# Learn Laravel 13

A collection of practical projects and lessons created while learning **Laravel 13**.

This repository is my hands-on workspace for exploring Laravel concepts, building small applications, and improving my PHP and Laravel development skills.

## Projects

| Project | Description |
|---|---|
| [`project-my-notes`](./project-my-notes) | A notes management application demonstrating authentication, CRUD operations, Eloquent ORM, Blade, and authorization policies. |
| `lessons` | Practical exercises and examples while learning Laravel concepts. |
| `project-second` | Another standalone Laravel application for practice. |

## Tech Stack

- PHP
- Laravel 13
- Composer
- MySQL / SQLite
- Blade
- JavaScript, CSS, and Vite

## Getting Started

Each project is a separate Laravel application with its own dependencies and environment configuration.

1. Clone the repository:

   ```bash
   git clone https://github.com/techgovinda1/learn-laravel-13.git
   cd learn-laravel-13
   ```

2. Open the project you want to run:

   ```bash
   cd project-my-notes
   ```

3. Follow that project's `README.md` for installation and setup instructions.
